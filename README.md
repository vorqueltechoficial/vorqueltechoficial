# Volquen Tech - Website

Website profissional da **Alven Tech**, empresa especializada em soluções tecnológicas inovadoras para transformação digital de negócios.

## 🎯 Sobre o Projeto

Alven Tech é uma empresa que oferece soluções digitais completas incluindo:
- 🎨 Projetos Digitais
- 🌐 Criação de Websites
- 🛍️ E-commerce e Catálogos Online
- 📊 Sistemas de Gestão
- 💬 Automação com WhatsApp
- 📱 QR Codes Personalizados

## ✨ Características

- **Design Moderno**: Interface elegante com paleta de cores (Verde Neon #00FF00 + Amarelo #FFD700)
- **Animações Fluidas**: Efeitos suaves e profissionais em toda a página
- **Fundo Interativo**: Colmeia dinâmica que reage ao movimento do mouse
- **100% Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Performance Otimizada**: Carregamento rápido e eficiente
- **Smooth Scroll**: Navegação suave entre seções

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos avançados com animations e gradientes
- **JavaScript Vanilla** - Interatividade sem dependências
